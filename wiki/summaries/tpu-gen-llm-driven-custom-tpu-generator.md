# TPU-Gen LLM-driven custom TPU generator

TPU-Gen is an LLM-based framework that automates custom tensor processing
unit generation. It focuses on systolic array designs. It supports exact and
approximate units. It uses RAG to address data scarcity and hallucinations.
It turns high-level specs into optimized low-level implementations.
Experiments show large area and power reductions versus manual baselines.
